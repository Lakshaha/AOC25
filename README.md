Welcome — this repo contains my Advent of Code 2025 solutions, implemented in Python.
Each day has its own folder with the puzzle input, the short problem statement (for quick reference), and one or more solution files.

What belongs in each Day folder

input.txt — puzzle input (seperate for everyone in the Event)

Question.txt — The puzzle and the sample case solved.

solution.py — Python script containing a clear part_1(), part_2() and main() that produces both Part 1 and Part 2 outputs.
